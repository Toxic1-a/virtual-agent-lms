# الوكيل الافتراضي — بيئة تعلم إلكتروني بحثية

منصة تعليم إلكتروني عربية RTL لدراسة أثر أسلوب عرض الوكيل الافتراضي (ثابت مقابل متحرك) مع تطابق كامل في المحتوى والتنقل والأنشطة.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر (عادة `http://127.0.0.1:5173/`).

من الهيدر يمكنك التبديل بين:
- **أ ثابت** — وكيل بصورة ثابتة
- **ب متحرك** — نفس الوكيل بحركة Lottie

الاختيار يُحفظ محلياً في المتصفح.

## التقنية

React + Vite + TypeScript + Tailwind CSS + Framer Motion + React Router + Lottie

## التقدم

يُحفظ محلياً في `localStorage` بدون تسجيل دخول.
